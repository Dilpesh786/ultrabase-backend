Quick SDK Integration Code

તમારી કોઈપણ વેબસાઈટ કે HTML પેજમાં આ રીતે UltraBase SDK જોડો:

<script src="https://ultrabase-backend.onrender.com/ultrabase.js"></script>
<script>
  const ultrabase = createUltraBase('https://ultrabase-backend.onrender.com');

  // Register User
  ultrabase.register('user@example.com', 'password123');

  // Submit UTR
  ultrabase.submitUTR('user@example.com', '123456789012');
</script>
